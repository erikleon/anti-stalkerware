## Affected Pages/Routes
- OSINT → unlocked sender → Online checks → "Where does a username exist?" — site count, not-checked list, sensitive-categories checkbox, grouped results.
- Settings — nothing new expected; confirm no change.

## Key Interactions to Verify
- The disclosure names how many sites will be contacted and lists the not-checked ones (protected, broken, failed verification) before the click.
- Ticking "Also check dating, adult, health, and political sites" raises the site count shown before the click, and shows its warning.
- Results are grouped: found first, then couldn't tell (with reason), then not found (collapsed).
- A found result shows the profile URL as selectable text only; nothing opens it.
- The button is disabled while a check runs; a second click does not start a second check.

## Edge Cases
- Invalid handle (spaces, slashes, "?", 1 or 41+ characters): button disabled, and main process refuses it too.
- Handle with characters in a site's strip_bad_char: that site gets the stripped handle; others unchanged.
- No network: every site "couldn't tell", none "no account".
- A bot-block or captcha page with status 200: "couldn't tell", not "found".
- Bundled dataset missing or hash mismatch: a clear error on the screen, not a check against zero sites.
- Sender below the abuse threshold: the channel refuses (gate), the section never shows.
- Leaving the OSINT screen mid-check and coming back.
- Locking the vault mid-sweep: the check stops; nothing appears after unlock.
- Skip list unreachable: the check runs on the bundled pass list and says so.
- A redirect to http:, an IP address, or a 4th hop: "couldn't tell", never followed.
- A response over 1 MB: "couldn't tell (page too large)".

## Critical Paths
- Import a threat → model flags it → OSINT opens → check a handle → results grouped with the caveat that a taken name isn't the same person.
- Pin bump: run scripts/verify-whatsmyname.mjs → manifest's verified list changes → CI green → installer bundles the pinned file (check release/…/Resources/models).
- Weekly workflow: failing sites open or update one GitHub issue; test.yml unaffected.
